# Refinement diagnostics

Read after a correction fails repeatedly or when documenting a multi-pass repair.

Classify the error before choosing a method: reference interpretation, global/local proportion, silhouette, depth, structural connection, sculpt form, topology, weights, rig, animation, material or export. A repeated visual guess calls for an overlay or landmark measurement. Repeated brush drift can call for bounded regional deformation. A stubborn surface patch can call for local retopology. Repainting weights without progress calls for pivot and topology inspection.

Record each consequential iteration's defect, hypothesis, changed region, expected effect, actual evidence, regressions and decision. Keep approved areas explicitly protected. Match the cost of evidence to the edit: fixed front/side/three-quarter for form, relevant pose for deformation, key frames for animation. Do not create an arbitrary fixed number of retries; stop or switch approach once evidence shows the method is ineffective.
