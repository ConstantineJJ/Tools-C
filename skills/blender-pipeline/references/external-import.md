# External model intake and repair

For a supplied or already imported model, use the canonical
[Imported asset recovery](../../blender-imported-asset-recovery/SKILL.md) and its
[inspection procedure](../../blender-imported-asset-recovery/references/inspection.md).
They own intake diagnosis, local recovery and semantic part separation. Any
supplier or licensed source is supported; no provider is required. Do not reimport
over a production asset merely to start inspection.

Read-only assessment remains [verification](../../verification/SKILL.md). Focused
rig, animation, export and engine tasks keep their specialist owners; an imported
asset does not automatically require all pipeline stages. Preserve provenance
uncertainty and consumer dependencies. Import success alone does not establish
visual quality, deformation, production readiness or release rights.
