# Blender sculpting compatibility pointer

The canonical sculpting owner is [blender-sculpting](../../blender-sculpting/SKILL.md).
Read that skill for organic/hard-surface sculpting, bounded corrections,
Dyntopo/voxel-remesh/Multires decisions, topology-loss safeguards and retopology
handoff. This legacy reference contains no independent production rules.

For scripted regional operations, the canonical sculpting skill may additionally
load [bounded sculpt operations](techniques/sculpt-operations.md).
