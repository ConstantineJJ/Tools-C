# Optional source adapter: Tripo

Tripo is a temporary external source, not an installation or runtime dependency.
For each delivery record source filename, supplied formats, export date/options,
known authorship/license (unknown if unverified), and which geometry, UV, PBR maps,
rig, skinning and animations were actually delivered. No account or API required.

Pass the file into the generic [external import workflow](../skills/blender-pipeline/references/external-import.md).
Infer neither skeleton size nor production readiness from the provider name.
Clip names and bone mappings are local asset/profile data. A different provider
needs only another optional source note. Blender-native authoring remains complete
without this note or a subscription.
