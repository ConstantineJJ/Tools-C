# Tools_C v4.0.1

First packaged release of the current Tools_C agent tooling: 24 canonical skills,
nine legacy Blender entrypoints and JSON contract/profile schema 1.

## Included

- Complete Blender domain pack: architecture, environment assets, roads and
  infrastructure, props, vehicles, products/electronics, vegetation and sculpting.
- [Posteffects and polishing](../../skills/blender-posteffects-polishing/SKILL.md):
  late material/texture finishing, localized wear, surface damage and motivated
  emission/glow before final visual QA and delivery.
- Visual feedback workflow: capture, inspect, correct, recapture and inspect;
  Python-image and saved-candidate offline capture fallbacks.
- Declarative domain and polishing contracts protecting canonical registration,
  activation, compatibility targets and required ownership/evidence links.
- English/Russian stage routing, read-only/preservation boundaries and complete
  finishing context delivery even with a cached legacy reader.
- Standard-library checkers, project bootstrap, managed legacy-router sync,
  snapshots, capture/export validation and MCP deployment diagnostics.

## Download and use

Download `Tools_C-v4.0.1.zip`, verify it against `SHA256SUMS.txt` and extract it.
The archive contains canonical skills, tools, documentation, tests and dated
evidence. It excludes Git metadata, ignored local files and external integration
worktrees. No installer or engine binary is included.

Python 3.10+ is required. From the extracted `Tools_C-v4.0.1` directory on Windows:

```powershell
.\check.bat --self
```

If Python is not on PATH, set `TOOLS_C_PYTHON` to its executable for this session.
For project/MCP integration, follow the [README](../../README.md): configure the
actual extracted Tools_C root and regenerate managed routers from that location.
The GitHub release does not replace a running MCP server or install plugins.

## Verification and limits

The implementation checkpoint has 94 passing regression tests, Tools_C L1
26 PASS / 0 WARN / 0 FAIL, integration L1 9 PASS / 0 WARN / 0 FAIL and 16/16
actual connector context comparisons. All nine legacy contexts were validated.
The release assets also contain `release-verification.json` with the exact source
commit, archive hash and fresh extracted-package checks.

L1 never starts Blender/Godot. Structural checks and routing evidence do not
certify a production model's appearance, deformation, animation or target-engine
behavior. Those remain separately scoped evidence gates. Optional skill-creator
validation needs PyYAML; Tools_C's own checks use the standard library.
