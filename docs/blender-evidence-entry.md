# Blender evidence entry for combined tasks

Required evidence remains in [the complete guide](blender-evidence.md). Read that
recipe before invoking snapshot/capture/export or their fallback. This entry
avoids delivering every API recipe with each domain in a combined modeling task.

Capture fixed relevant BEFORE views, open the actual images, diagnose and correct
the scoped defect, then recapture with comparable camera/frame/framing/resolution,
lighting and exposure. Inspect AFTER plus a protected alternate view. A returned
PNG is VISUAL REVIEW REQUIRED until observed; mesh checks never imply Visual PASS.

Solid captures support geometry. Managed material/rendered captures use bounded
Cycles and omit production compositor effects: they do not certify EEVEE-only toon
graphs, outlines, bloom or target-engine appearance. Inspect the actual requested
renderer/result for those criteria. Preserve source settings; keep unavailable
criteria open instead of substituting another renderer.

If named MCP capture is absent, use the guide's Python-image route or separately
render the saved candidate offline. Open the image. Missing acquisition is a named
blocker, not permission to finish from counts. Source snapshots protect only their
declared categories; fresh import and animation/input acceptance are separate.

Use [QA profiles](../skills/blender-pipeline/references/techniques/qa-profiles.md) for
local form/material/hierarchy checks and final saved-file verification. Record
actual observations, artifact identities and remaining owners.
