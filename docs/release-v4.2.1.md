# Tools_C 4.2.1

The main toolkit now has a private plugin entrypoint and Agent Vision evidence
capabilities. Thirty canonical owners and nine legacy Blender routes remain.
Catalog/profile/registration schema_version stays 1; existing QA receipts remain
readable. The reported toolkit architecture/version is now 4.2.1.

- Private `plugins/tools-c` routes to current canonical skills and existing
  registered Blender/Godot/files Apps. The supplied original icon is included.
  No production skill bodies, checker copies, server or frozen fallback are bundled.
- Existing capture supports optional named cameras and opaque silhouette alpha
  masks. Python captures can use rectangular images; prior defaults remain.
- Existing snapshot helper adds scoped evaluated world measurements.
- `vision_compare.py` verifies input hashes, measures silhouette IoU, symmetric
  contour distances and visible landmarks, produces contour/difference maps and
  localized findings. Camera mismatch is NOT_COMPARABLE; approximate/generated
  evidence cannot become technical metric acceptance.
- Existing QA can bind a comparison artifact, recompute its inputs and refuse
  stale/failed comparisons as accepted evidence. Artistic/export/runtime checks
  retain separate verdicts and existing owners.
- Existing MCP adapter adds only `tools_c_check`; all prior operation names
  remain. Capture parameters are extended with optional inputs only.
- Obsolete 4.0.1 release/publication files and 30 early archived report files
  are removed. The user removed the ignored local V1/v4 archive. Prior bytes
  remain in Git history; original skill
  source/lesson provenance and later feature reports are retained.

See [Agent Vision](agent-vision.md) and [private plugin](tools-c-plugin.md) for
interfaces and limits. After canonical changes regenerate managed Blender routers,
restart the existing MCP process and refresh its client metadata. Plugin install
does not grant local access or start services. Full semantic likeness, arbitrary
reference segmentation and Depth/Normal/ID analysis are not claimed by this patch.
